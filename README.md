# 🕯️ قلب الغموض (Heart of Mystery) | مسرح التحقيق الصوتي التفاعلي وعابر العوالم

**الرابط المباشر:** [https://labyrinth-of-shadows.pages.dev](https://labyrinth-of-shadows.pages.dev)

أول لعبة تحقيق واستنتاج جنائي عربية تفاعلية بالصوت تعمل مباشرة في المتصفح بدون تحميل، تجمع بين **القضايا البوليسية ذات الحقيقة الجنائية الثابتة (Locked Case Bibles)** وطور **«عابر العوالم: شذوذ القوانين الكونية»** الذي يدمج بين **100 قانون كوني فريد × 100 عقدة جنائية = 10,000 عالم قابل للعب**.

---

## ✨ أبرز المزايا

1. **طور عابر العوالم (`100 × 100 = 10,000` عالم فريد):**
   - في كل جولة أو قفزة عبر البوابة، تستيقظ في عالم مواز تغيرت فيه قاعدة كونية واحدة (مثل عالم تحكمه سلالة فصيلة الدم `AB` بوصفها سلالة آدم الحاكمة، أو عالم يستعبد فيه الكريستاليون البشر، أو عالم تحكمه خوارزمية التنبؤ بالجرائم، أو عالم عملة الأعمار المقتطعة).
2. **استنتاج جنائي حقيقي وشخصيات عربية أصيلة:**
   - كل قضية مبنية على دستور جنائي مقفل (`Case Bible`) يضم 3 مشتبه بهم لكل منهم صوته المستقل وحجة غيابه وكذبته، و4 أدلة مادية مترابطة، ولوحة ربط استنتاجية (`Corkboard`)، و5 نهايات حقيقية.
3. **أداء صوتي متعدد المشاعر وذاكرة تخزين مزدوجة (`Edge Cache + IndexedDB`):**
   - نطق عربي مضبوط داخليا بالحركات دون إزعاج عين القارئ بالتشكيل، مع تخزين دائم في متصفح اللاعب (`IndexedDB`) وتخزين سحابي على حافة Cloudflare (`caches.default`) لتقليص استهلاك الحصة اليومية إلى الصفر عند تكرار المقاطع.
4. **استوديو الانتشار الفيروسي وصناع المحتوى (`TikTok / Reels / Shorts Studio`):**
   - توليد فوري لسيناريوهات فيديو قصيرة (30 ثانية) بصيغة «ماذا لو استيقظت في عالم...» مع روابط تحد مباشرة (`?world=1-1`) وبطاقات نتيجة بصرية عالية الدقة (`1080×1350 Story PNG`) خالية من حرق الأحداث.
5. **أمان كامل لمفاتيح الـ API:**
   - يخزن مفتاح `GEMINI_API_KEY` حصرا داخل بيئة Cloudflare المشفرة (`Cloudflare Pages Encrypted Secret`) عبر الدالة الطرفية `functions/api/interactions.js` ولا يظهر أبدا في الكود المصدري للعميل.

## 🚀 التشغيل المحلي والنشر على Cloudflare Pages

### التشغيل المحلي:
```bash
npm start
```

### النشر على Cloudflare Pages:
```bash
npx wrangler pages deploy . --project-name=labyrinth-of-shadows --branch=main
```
